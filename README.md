# Commission Tracker

A Chrome extension for freelance artists to track their commissions — clients, deadlines, progress, payment status, and money earned.

</div>

## Features (planned)
- Track clients, request details, due dates
- Visual progress bar
- Payment tracking with custom payment methods

## Technical Details
- Built with **Manifest V3**
- Vanilla JavaScript, HTML, CSS
- Minimal permissions - only `storage` requested

## Status
🚧 In progress — currently building out the popup UI and storage logic.
